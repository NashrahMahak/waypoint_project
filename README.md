# Waypoint Trail Finder & Trip Planner

Waypoint is a trail-finding and trip-planning web application built with Python and Django. It features an object-oriented domain model for managing trail distances and hike tracking, integrated with a Django relational database and administrative interface.

---

## 🛠️ Setup Instructions

1. **Activate Virtual Environment:**
   * **Windows (Git Bash):**
     ```bash
     source env/Scripts/activate
     ```
   * **macOS / Linux:**
     ```bash
     source env/bin/activate
     ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
